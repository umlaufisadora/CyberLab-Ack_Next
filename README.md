# CyberLab
## Desenvolvedora
Isadora Umlauf
## Objetivo
Migrar uma aplicação HTML + Tailwind CSS para Next.js utilizando TypeScript.
## Tecnologias
- Next.js
- TypeScript
- React
- Tailwind CSS
- REST API (GitHub Search API)
- next/image
- next/font
## Funcionalidades
- Consumo de API em tempo real
- Listagem dinâmica de ferramentas de cibersegurança
- Componente reutilizável (CardFerramenta)
- Contador do Toolkit
- Estado de carregamento
- Renderização utilizando map()
## Desenvolvimento
Atividade desenvolvida individualmente, adaptando o projeto original
